Where are my save files?
  • Windows: %APPDATA%\SubwayBuilder\saves (paste that into Explorer's address bar)
  • macOS: likely ~/Library/Application Support/SubwayBuilder/saves
  • Linux: likely ~/.config/SubwayBuilder/saves

Drop the fixed file back into the same folder and it appears in the load menu as a separate save named "… FIXED". Your original save is never modified. (macOS/Linux paths are the standard Electron locations — confirmations welcome.)

What does it actually do?

Subway Builder connects tracks only when endpoint coordinates match exactly. The tool decompresses your save, builds the track graph, finds endpoint pairs closer than the threshold that belong to disconnected sections of your network, and snaps them to identical coordinates (elevations are checked too, so it won't weld different depths together). Legitimate parallel tracks are ~5 m apart and are never touched. The repaired save is re-packed with a fresh ID so it can't collide with the original.

Privacy: all analysis and fixing happens in your browser. The only network requests are for the base map imagery (OpenStreetMap data rendered by CARTO) — your save file itself is never uploaded anywhere.
